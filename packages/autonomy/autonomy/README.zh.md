# @deepseek-ai/dsh-autonomy

[English](README.md) | 中文

## 概述

加载该插件，一个设置即可启动整个自主系统。它会挂载安全核心、记忆、执行循环、效率、自主提示词、工作流、学习、演化和研究层，全部共用一个 `stateDir`。每个部分都有自己的 `enabled` 开关；演化和研究层默认关闭。随后套件把模型接入执行器：规划器向模型请求 JSON 计划，逐一核对工具名是否在已知列表中，若计划存在重复 id 或循环，则退回为简单的顺序执行。步骤执行者让模型一次调用一个工具，最多六轮。每次工具调用仍经过常规工具运行时，因此授权、审批、预算和审计日志都会生效。工作流中的智能体节点使用同一模型。模型来自配置中的 `model`，否则使用智能体的默认模型。规划器最多看到 `plannerTools` 个工具，按工具检索排序。
