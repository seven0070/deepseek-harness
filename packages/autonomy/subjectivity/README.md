# @deepseek-ai/dsh-subjectivity

English | [中文](README.zh.md)

## Summary

Off by default; with `enabled: false` the plugin does nothing. When enabled it provides `ctx.subjectivity`, a passive recorder that other plugins can feed, and a read-only `subjectivity_report` tool. It measures four indicators loosely based on Butlin, Long et al. (2023): metacognition (whether confidence tracks accuracy), self-model stability, global availability of focus content (global workspace theory), and agency. It never changes the agent's behaviour, prompts or goals. Every report states that these are research indicators, not evidence that the system is conscious or has experiences.
