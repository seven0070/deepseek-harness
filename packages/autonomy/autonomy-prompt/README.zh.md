# @deepseek-ai/dsh-autonomy-prompt

[English](README.md) | 中文

## 概述

向系统提示词添加两个部分。基本准则是自主智能体的一组固定规则：它是谁、可以做什么、如何计划和验证，以及如何对待不确定性和诚实。其中会填入实时信息（身份、当前目标、紧急停止开关状态），并属于受保护核心，智能体无法修改。已学指导原则部分随时可以修改。默认情况下（`changes: open`），智能体在对话中用 `prompt_edit` 直接修改：当你要求它添加、修改或删除某条指导原则时，或者它从纠正或任务中学到东西时。设置 `changes: approve` 后，它改用 `prompt_propose`，每次修改都要等你批准。你也可以自己编辑 Markdown 副本（`guidelines.md`，与 JSON 文件放在一起），修改会在下一轮生效。智能体做出的修改如果会削弱安全规则，就会被拒绝。所有版本都会保留，`prompt_revert` 可以恢复任意早期版本，`prompt_guidelines` 显示当前列表和历史。
