# @deepseek-ai/dsh-autonomy-prompt

[English](README.md) | 中文

## 概述

向系统提示词添加两个部分。基本准则是自主智能体的一组固定规则：它是谁、可以做什么、如何计划和验证，以及如何对待不确定性和诚实。其中会填入实时信息（身份、当前目标、紧急停止开关状态），并属于受保护核心，智能体无法修改。已学指导原则部分由智能体在对话中逐步建立：当所有者纠正它或某项任务让它学到东西时，它会调用 `prompt_propose` 来添加、替换或删除一条简短的指导原则。每次修改都需要所有者批准，会削弱安全规则的修改会被拒绝，所有修改都有版本记录，`prompt_revert` 可以恢复任意早期版本。`prompt_guidelines` 显示当前列表和历史。
