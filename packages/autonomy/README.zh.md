# autonomy/：自主执行智能体

[English](README.md) | 中文

## 概述

自主包组让 harness 成为能够安全地自主追求目标的智能体。每个部分都是独立的 Cordis 插件，可以单独加载、替换或移除；`autonomy` 可一次加载全部。安全核心总是最先加载，智能体无法修改它。

## 包

| 包 | 作用 |
| --- | --- |
| `autonomy` | 一键套件；把模型接入为规划器和步骤执行者。 |
| `autonomy-core` | 安全核心：身份、紧急停止、授权与审批、预算、审计日志。 |
| `executive` | 目标、计划、信念，以及带检查和重试的自主循环。 |
| `efficiency` | 工具检索、输出压缩、带逐次费用的运行日志。 |
| `autonomy-prompt` | 宪章加上习得的准则，可在对话中修改。 |
| `workflows` | 由智能体提出、经所有者审核后才运行的工作流。 |
| `learning` | 技能优化、实验，以及经批准的新能力。 |
| `evolution` | 沙箱中的自我改进，带评估关卡和经批准的上线。 |
| `subjectivity` | 仅用于研究的测量；默认关闭。 |
